# 📸 Imágenes del PANEL ADMINISTRATIVO (`/admin`)

Pruebas en `public/images/admin/`. Reemplaza manteniendo el nombre y `Ctrl+F5`.
Regenerar: `php scripts/generate_panel_placeholders.php`

| Archivo | Dónde va en el panel admin |
|---|---|
| `banner.jpg` | Fondo del banner "Panel Administrativo" (zona superior, detrás del título y la cita) |
| `card-anime.jpg` | Tarjeta superior **Anime** (junto al Total y botón rojo) |
| `card-manga.jpg` | Tarjeta superior **Manga** (botón púrpura) |
| `card-musica.jpg` | Tarjeta superior **Música** (botón azul) |
| `sidebar.jpg` | Decoración tras la cita del menú lateral izquierdo |

Tamaños: banner 1400×420 · cards 420×250 · sidebar 360×900.
