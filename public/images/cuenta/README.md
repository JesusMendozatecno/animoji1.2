# 📸 Imágenes del PANEL DE CUENTA (`/profile`)

Pruebas en `public/images/cuenta/`. Reemplaza manteniendo el nombre y `Ctrl+F5`.
Regenerar: `php scripts/generate_panel_placeholders.php`

| Archivo | Dónde va en la pestaña Cuenta |
|---|---|
| `banner.jpg` | Fondo del banner superior con el texto japonés "自己を信じて、進み続けろ" |
| `avatar.png` | Foto de perfil en la tarjeta de usuario (también la usa el menú desplegable del header) |
| `sidebar.jpg` | Decoración tras la cita del menú lateral (Cuenta / Cambiar contraseña / Borrar cuenta / Volver) |
| `promo.jpg` | Tarjeta "Tu cuenta, tu mundo" (esquina inferior derecha) |

Tamaños: banner 1400×300 · avatar 128×128 (transparente) · promo 640×420.
